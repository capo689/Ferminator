## Scope and applicability

Ferminator is a public, hosted, multi-profile job-search application. It handles
personal career and email data, connects to external ATS platforms and Supabase,
runs scheduled jobs, and can deliver email. Payments, uploads, user-generated
content, AI agents, and mobile clients are not currently in scope.

The FINISHER 1.1.0 catalog contains 173 checks. Context gating marked 130 checks
applicable, and all 130 were assessed.

- Render service: `ferminator-web` (`srv-d9i4jofavr4c73a516mg`).
- Production URL: `https://ferminator-web.onrender.com`.
- Current deployment was live and healthy during the audit.

- Successful health responses include CSP, `X-Content-Type-Options`,
  `Referrer-Policy`, `Permissions-Policy`, and a request ID.
- HSTS, `X-Frame-Options`, COOP, and CORP were absent. The 401 response bypassed

- Deploy history provides rollback controls, but no executed rollback drill was
  evidenced. There is no separate staging or preview environment.

## Supabase verification

- Project: `Ferminator` (`mwqpujvtymillduxlwdg`), healthy at audit time.
- Supabase security advisors returned zero findings.
- Performance advisors reported informational unused indexes.
- Postgres logs contained a `job_matches` upsert that waited approximately
  109 seconds for a `ShareLock`, creating a material reliability risk.
- Earlier logs also showed an ambiguous-column error and a missing-column error.
- API health traffic returned HTTP 200.
- RLS policies exist in migrations, but hosted User A/User B isolation was not
  demonstrated. The application uses a privileged server-side database connection,
  so RLS is not an independently verified defense for application queries.
- Backup settings and an executed restore drill were not verified.

## Principal limitations

- Authentication is a shared HTTP Basic credential rather than managed identity.
- There is no session lifecycle, password reset, revocation, logout, or login
  throttling.
- No staging environment, SAST job, DAST run, authorization matrix test, real
  database integration suite, fuzzing, synthetic monitoring, tracing, or production
  error tracker was evidenced.
- Privacy policy, terms, operational data-rights workflow, and support path are absent.
- Email sending is not configured in the observed production run, and bounce or
  complaint handling is not implemented.
- Product-outcome telemetry is absent.

This document records observed evidence and limitations; it does not claim a
runtime check passed solely because supporting code exists.
