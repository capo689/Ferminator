# Ferminator Builder Handoff

This package contains:

- `Ferminator-Style-Guide.pdf` - complete design and page-by-page implementation guide.
- `screens/` - nine approved visual references, normalized and numbered.
- `assets/svg/` - transparent, resolution-independent creative assets.
- `assets/png/` - transparent PNG renditions of the same custom assets.
- `assets/fonts/` - production web fonts and licenses.
- `assets/design-tokens.css` and `.json` - implementation-ready design tokens.
- `asset-manifest.json` - machine-readable inventory.

Use SVG assets whenever possible. PNG files are supplied for tools or runtimes that cannot render SVG. Company marks are controlled geometric prototype vessels; production integrations should replace them with authorized company marks while preserving the 48px vessel and neutral treatment.

Use Lucide for standard interface icons at 1.75px stroke weight. Those standard icons are not duplicated here.
